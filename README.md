# ВентСмета

Калькулятор вентилируемого фасада. Считает площадь, подсистему, облицовку, утеплитель, крепёж и смету. Работает в браузере, проекты хранятся локально.

## Что умеет

- Геометрия: площадь целиком или стены по отдельности, окна и двери
- Облицовка: керамогранит, композит, фиброцемент, камень, кассеты, HPL, профлист
- Подсистема: оцинковка / алюминий / нержавейка, схемы вертикальная / горизонтально-вертикальная / межэтажная
- Теплотехника по СП 50.13330 и ветровой район
- Спецификация с запасом, цены, монтаж, НДС
- Сравнение трёх материалов подсистемы
- Разрез стены
- Сохранение проектов в браузере и печать сметы

## Запуск

```bash
npm install
npm run dev
```

Откроется http://localhost:5173

Сборка:

```bash
npm run build
npm run preview
```

## Стек

React 19, TanStack Start, Vite, Tailwind CSS 4, Zustand.

Данные никуда не отправляются — только `localStorage` в вашем браузере.
